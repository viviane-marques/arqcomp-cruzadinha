# 🔌 Conecta os Fios

Jogo de Arquitetura Computacional feito em HTML, CSS e JavaScript puros, no estilo "ligue os pontos". Cada pista é um círculo numerado colorido. Arraste um fio até o círculo branco da resposta certa e preencha todas as casas do tabuleiro.

**Jogue aqui:** https://viviane-marques.github.io/connect-boot/

## Como jogar

1. Leia as pistas numeradas na lista ao lado do tabuleiro.
2. Arraste (mouse ou dedo) a partir do círculo colorido com o número da pista até o círculo branco com a resposta certa.
3. Fios de cores diferentes não podem se sobrepor: se um fio passar por cima de outro, ele corta o fio antigo.
4. Para refazer um fio, arraste de novo a partir do círculo numerado.
5. Clique em **Conferir**: as pistas certas ficam com ✓ e as erradas com ✗.
6. O contador mostra quantas palavras estão certas ("X de 12 palavras").
7. Para vencer, acerte todas as palavras e preencha todas as casas.
8. **Reiniciar** solta todos os fios. **Novo jogo** sorteia 12 palavras e um novo tabuleiro.

## Palavras e pistas

Cada partida usa 12 destas 16 palavras.

| Resposta | Pista |
|----------|-------|
| CPU | Cérebro do computador: busca, decodifica e executa as instruções dos programas. |
| ULA | Parte da CPU que faz as contas e as operações lógicas. |
| UC | Parte da CPU que comanda e coordena o que os outros componentes fazem. |
| REGISTRADORES | Minúsculas memórias dentro da CPU, as mais rápidas, guardam dados em uso imediato. |
| RAM | Memória principal e volátil que guarda programas em execução e perde tudo sem energia. |
| ROM | Memória permanente gravada na fabricação, mantém o conteúdo mesmo sem energia. |
| EEPROM | Memória permanente regravável por sinais elétricos, que permite alterar um único byte por vez. |
| FLASH | Memória permanente regravável em blocos, usada em pendrives e SSDs. |
| CACHE | Memória pequena e veloz entre CPU e RAM que guarda dados usados com frequência. |
| MEMORIADEMASSA | Guarda arquivos e programas por muito tempo, em grande capacidade, como um HD. |
| DMA | Mecanismo que move dados entre memória e periféricos sem ocupar a CPU. |
| ADDRESSBUS | Caminho de mão única por onde a CPU informa a posição de memória desejada. |
| DATABUS | Caminho de mão dupla por onde trafegam os valores lidos e escritos entre componentes. |
| MICROCONTROLADOR | Chip com processador, memória e portas de entrada e saída, típico de sistemas embarcados. |
| DUALCORE | Processador com dois núcleos de execução no mesmo chip. |
| QUADCORE | Processador com quatro núcleos de execução no mesmo chip. |
